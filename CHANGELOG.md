# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по
[SemVer](https://semver.org/lang/ru/).

## [4.0.0] — 2026-11-22

Переписанная версия продукта: фичи из экспериментальной 3.0 перенесены в
React/TypeScript-приложение, закрыты все найденные дефекты, добавлены
автотесты и документация.

### Добавлено

- Приоритеты, фильтры со счётчиками, поиск по всем словам с подсветкой.
- Экспорт/импорт JSON с подтверждением, поэлементной валидацией и счётчиком
  пропущенных записей.
- Отмена последнего удаления, очистки выполненных и импорта из уведомления.
- Компактный вид, тёмная тема по системной настройке.
- Локализация ru/en через `_locales`; манифест и UI переводятся.
- Клавиатурная перестановка задач (пробел + стрелки) и `Alt+A` / `Alt+S` / `Esc`.
- Единая схема хранения (версия 4) с миграцией из 1.x (`localStorage`) и 3.0
  (`tasks_v3`); копия перенесённых данных сохраняется в `legacyBackup`.
- Иконки 16/32/48/128.
- Автотесты: 53 юнит-теста, 23 статические проверки, 50 браузерных проверок и
  40 шагов E2E в настоящем Chrome.
- Документация: `docs/knowledge-base.md`, `docs/decisions.md`, `docs/testing.md`,
  `PRIVACY.md`, тексты для магазина в `store/`.

### Исправлено

- Перестановка задач с высоким приоритетом не работала (сортировка по двум ключам
  при записи одного).
- На каждом рендере добавлялся новый слушатель `click` на `document` (утечка).
- Изменение storage из другого окна стирало черновик в поле ввода.
- Любое действие сбрасывало позицию скролла и фокус.
- Состояние панели терялось при выгрузке service worker: popup показывал
  «Открыть» при открытой панели.
- Одна битая запись в файле импорта отменяла весь импорт.
- Отмена (undo) из уведомления не срабатывала: колбэк читал устаревшее состояние.
- Лишние разрешения `tabs`, `activeTab`, `commands`, `clipboardWrite`; проверка
  `chrome://` по `tab.url` не работала без них.
- Отсутствие `minimum_chrome_version` при вызове `chrome.sidePanel.close()`
  (Chrome 141+): на старых версиях кнопка закрытия молча ломалась.
- `Intl.RelativeTimeFormat` со `style: "narrow"` давал «-2 мин» вместо «2 мин. назад».

### Изменено

- Требуется Chrome 116+ (ранее 114 без гарантий).
- Хранилище: ключ `tasks` вместо `tasks_v3`; старые данные переносятся
  автоматически, потери списка при обновлении больше нет.

## [3.0.0] — 2026-04

Экспериментальная переписка на vanilla JS: приоритеты, фильтры, поиск,
экспорт/импорт, компактный режим. Не публиковалась; заменена версией 4.0.

## [1.0.0] — 2026-03

Первая версия: React + TypeScript + Vite/CRXJS, drag&drop на dnd-kit, задачи в
`localStorage`, popup с горячей клавишей.
