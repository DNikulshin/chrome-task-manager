# Chrome Web Store — карточка (ru)

**Название:** Менеджер Задач — список в боковой панели

**Краткое описание (до 132 символов):**
Список задач в боковой панели Chrome: приоритеты, фильтры, поиск, экспорт. Без аккаунта и без сети.

**Категория:** Продуктивность / Инструменты
**Языки:** русский, английский

## Полное описание

Задачи всегда под рукой — в боковой панели Chrome, рядом с текущей вкладкой.
Ничего не нужно переключать: панель открывается кликом по иконке или Ctrl+B.

ЧТО УМЕЕТ
• Добавление по Enter, редактирование, удаление с подтверждением
• Высокий приоритет: флажок и бейдж «важно»
• Порядок задач перетаскиванием — мышью, с клавиатуры (пробел + стрелки) и на тач-экране
• Фильтры «Все / Активные / Готово» со счётчиками и поиск с подсветкой
• Отмена последнего удаления, очистки и импорта — прямо из уведомления
• Экспорт и импорт JSON: резервная копия и перенос между браузерами
• Компактный вид и тёмная тема
• Русский и английский интерфейс

ПРИВАТНОСТЬ
Расширение не делает сетевых запросов. Задачи хранятся только в вашем браузере
(chrome.storage.local). Нет аналитики, нет аккаунта, нет доступа к содержимому
страниц.

РАЗРЕШЕНИЯ
• sidePanel — показать интерфейс в боковой панели
• storage — хранить задачи и настройки локально

ЧЕГО НЕТ
• Синхронизации между устройствами (для переноса используйте экспорт/импорт)
• Напоминаний и уведомлений (в планах)

## Обоснование разрешений (для ревьюера)

- `sidePanel` — единственный способ показать интерфейс расширения в боковой панели.
- `storage` — хранение списка задач и настроек в `chrome.storage.local`.
- Разрешения `tabs`/`activeTab`/`host_permissions` не запрашиваются: расширение не
  читает страницы и не обращается к сети. Недоступность панели на `chrome://`
  определяется по ошибке `chrome.sidePanel.open()`.
